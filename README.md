# menu-driven-calculator-java
This is a Java-based menu-driven calculator that performs basic arithmetic operations using modular methods and user input validation.

Features:
-Addition
-Subtraction
-Multiplication
-Division
-Loop-based menu system
-Division by zero handling

Technologies Used:
-Java
-Scanner class

How to Run:
1. Compile the program: javac Calculator.java
2. Run the program: java Calculator
